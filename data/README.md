# data/

This folder does **not** contain raw datasets.

CheXpert and IU X-Ray / Open-I are stored outside the repository and located via
`configs/paths.yaml` (created from `configs/paths.example.yaml`, git-ignored).
Raw dataset folders are read-only: nothing in this project writes to them.

| Path | Purpose | Tracked in Git |
|---|---|---|
| `splits/` | Patient-level split definitions (lists of IDs), generated by scripts. Empty until splits are created. | Yes |
| `cache/` | Regenerable intermediate artifacts (e.g. resized images, parsed metadata). | No |
| `raw/` | Reserved; must never hold dataset copies. | No |

Split files must be produced by code in this repository so they can be
regenerated and audited. No patient may appear in more than one split.
