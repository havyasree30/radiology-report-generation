# Final test table captions

**Table 1. Locked-test population.** Population flow from the 578 locked studies to the primary set, the clinical-finding subset and the routing counts.

**Table 2. Final classifier metrics.** Macro and micro ranking and threshold metrics, Brier score, log loss and ECE with 95% study-level bootstrap intervals.

**Table 3. Per-class classifier metrics.** AUROC, AUPRC, precision, recall, specificity, F1 and support per observation.

**Table 4. Final retrieval metrics.** Jaccard, nDCG, finding coverage, Hit and duplicate-text rate at K = 1, 3, 5, 10 for the classifier query and the oracle query, and their gap.

**Table 5. Final report-generation metrics.** Finding-level and text-overlap metrics on the locked test.

**Table 6. Three-state system metrics.** State distribution, routing by reference state, decided-case recalls, decision coverage, abstention and routing/prose consistency.

**Table 7. Rare-finding analysis.** Test support, precision, recall, F1 and classifier true-positive retention for the six rare findings.

**Table 8. Validation-to-test comparison.** Descriptive test minus validation differences for classification, retrieval, report generation and system metrics.

**Table 9. Failure analysis.** Frozen failure taxonomy over the clinical subset.

**Table 10. Runtime and compute.** Classifier, retrieval and generation runtime, tokens, GPU memory and model metadata.

**Table 11 (supplementary). Provenance of stated findings.** Classifier only, retrieval only, both, neither, with reference support.

**Table 12 (supplementary). Copying.** Sentence copying, whole-report copying and repeated-sentence rate with the frozen definitions.
