## Known weaknesses

- **AUROC below 0.75:** Enlarged Cardiomediastinum, Lung Opacity, Consolidation, Atelectasis.
- **Thresholded precision below 0.15:** Enlarged Cardiomediastinum, Lung Lesion, Consolidation, Pneumonia, Pleural Other, Fracture.
- **Recall below 0.70:** Enlarged Cardiomediastinum, Lung Lesion, Pneumonia, Pleural Other.
- **Over-calling at the Youden operating point:** 5.05 predicted vs 2.40 actual positive findings per image.
- **Mild overfitting:** val loss minimum at epoch 2, selected epoch 5. Single seed, so no confidence intervals yet.

## Serialization fix

- **Before:** reading the original CSV with pandas' default (not correctly rounded) float parser produced 72 status mismatches (69 on valid entries) against the stored thresholds. The values written were in fact exact; the loss occurred on reading. This corrects the mechanism stated in the verification report.
- **After:** a lossless `.npz` (canonical), plus a 17-digit CSV read with `float_precision="round_trip"`. Max abs diff 0.0e+00; **0** mismatches.
